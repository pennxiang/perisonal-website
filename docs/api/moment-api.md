# 瞬间相关 API

## 1. 获取瞬间列表

获取所有瞬间列表，支持分页。

**接口地址**: `GET /api/v1/moments`

**请求参数**:

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | int | 否 | 1 | 页码 |
| size | int | 否 | 16 | 每页数量 |

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "content": [
      {
        "id": 1,
        "title": "Bug 终于解决了",
        "content": "原来是 Redis TTL 序列化字段遗漏，修好那刻和平常的晚风一样轻盈。",
        "publishDate": "2024-11-14T22:15:00"
      },
      {
        "id": 2,
        "title": "今日感悟",
        "content": "下班路上的夕阳像提交后的服务，短暂、热烈，也值得停下来看一眼。",
        "publishDate": "2024-11-15T18:30:00"
      }
    ],
    "page": 1,
    "size": 16,
    "total": 89,
    "totalPages": 6
  }
}
```

## 2. 获取瞬间详情

根据瞬间ID获取详细内容。

**接口地址**: `GET /api/v1/moments/{id}`

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | long | 是 | 瞬间ID |

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "title": "Bug 终于解决了",
    "content": "原来是 Redis TTL 序列化字段遗漏，修好那刻和平常的晚风一样轻盈。经过两天的调试，终于找到了问题的根源。这次经历让我更加重视序列化配置的细节。",
    "publishDate": "2024-11-14T22:15:00",
    "tags": ["开发", "Redis"]
  }
}
```
